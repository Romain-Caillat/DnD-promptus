# Promptus

A self-hosted narrative engine for tabletop RPGs, played fully remote:
the GM prepares an AI-generated campaign and runs it with an LLM co-GM;
players play from their phones.

**Status:** rewrite in progress (Rust/Axum + React + Tauri). Design
comes first — see `TICKETS.md` and `docs/design-brief.md`. The V1
(Next.js) is archived in `archive/promptus-v1-nextjs.zip`.

- `CLAUDE.md` — vision, stack, structure
- `MEMORY.md` — durable decisions and invariants
- `TICKETS.md` — backlog
