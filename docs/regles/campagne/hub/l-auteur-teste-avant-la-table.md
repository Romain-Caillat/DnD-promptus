# L'Auteur teste avant la table

**État** : à définir

**Question** : comment l'Auteur s'assure-t-il qu'un chapitre tient avant de le jouer avec les autres ?

**Options** : jouer seul le chapitre · simulation automatique · relecture seule.

**Recommandation** : jouer seul, avec les combats simulés qui existent déjà.

**Schéma** :

```text
 chapitre préparé ──▶ l'Auteur le joue seul ──▶ corrige ──▶ soirée
```

**Pourquoi** : le Brasier a montré que des règles non testées cassent la table.
