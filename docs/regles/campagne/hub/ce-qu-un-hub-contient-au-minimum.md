# Ce qu'un hub contient au minimum

**État** : à définir

**Question** : combien de contenu faut-il pour remplir un hub d'une heure à six ?

**Options** : seuil fixe · seuil selon le nombre de joueurs · pas de seuil.

**Recommandation** : seuil fixe ci-dessus, provisoire jusqu'à la partie de test.

**Schéma** :

```text
 hub ─┬─ 4 PNJ parlants      ─┬─ 1 mini-jeu
      ├─ 2 quêtes secondaires ├─ 6 occasions de stat
      └─ branches d'échec     └─ convergence vers le fil
```

**Pourquoi** : c'est le vrai coût de l'Auteur ; sans seuil, un hub est vide ou interminable.

**Impacts** : jeu — le budget de temps d'une soirée · plateforme — la préparation compte et signale ce qui manque.
