# Difficulté

**État** : tranchée · 11/10/2026

**Règle** : La difficulté, mort comprise, est un réglage de campagne.

**Schéma** :

```text
 facile ◀──────────── réglage ────────────▶ mortel
 (relevé à coup sûr)                        (mort définitive possible)
```

**Détails** :

- La défaite du groupe reste toujours une branche préparée, jamais un game over.

**Pourquoi** : la mort est possible, mais chaque table choisit son risque.

**Impacts** : jeu — jets contre la mort, résurrection rare · plateforme — ticket `engine/set-death-difficulty`.
