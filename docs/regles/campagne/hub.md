# Hub

## Une occasion par stat
> **tranchée** 11/10/2026 · résolue par : —

```
 HUB  FOR bras de fer · DEX crochetage · CON concours de boisson
      INT énigme · SAG mensonge à flairer · CHA marchandage
```

- Chaque hub offre au moins une occasion par stat.
- La préparation le vérifie et signale la stat oubliée.

**Pourquoi** : chaque joueur doit trouver son compte, en combat et hors combat.
**↳ jeu** : chaque stat sert partout · **↳ plateforme** : un contrôle de couverture des stats à la préparation.

## Ce qu'un hub contient au minimum
> **à définir** · résolue par : —

```
 hub ─┬─ 4 PNJ parlants      ─┬─ 1 mini-jeu
      ├─ 2 quêtes secondaires ├─ 6 occasions de stat
      └─ branches d'échec     └─ convergence vers le fil
```

**Question** : combien de contenu faut-il pour remplir un hub d'une heure à six ?
**Options** : seuil fixe · seuil selon le nombre de joueurs · pas de seuil.
**Recommandation** : seuil fixe ci-dessus, provisoire jusqu'à la partie de test.

**Pourquoi** : c'est le vrai coût de l'Auteur ; sans seuil, un hub est vide ou interminable.
**↳ jeu** : le budget de temps d'une soirée · **↳ plateforme** : la préparation compte et signale ce qui manque.

## L'Auteur teste avant la table
> **à définir** · résolue par : —

```
 chapitre préparé ──▶ l'Auteur le joue seul ──▶ corrige ──▶ soirée
```

**Question** : comment l'Auteur s'assure-t-il qu'un chapitre tient avant de le jouer avec les autres ?
**Options** : jouer seul le chapitre · simulation automatique · relecture seule.
**Recommandation** : jouer seul, avec les combats simulés qui existent déjà.

**Pourquoi** : le Brasier a montré que des règles non testées cassent la table.
**↳ jeu** : — · **↳ plateforme** : une partie solo de test, sans effet sur la vraie campagne.
