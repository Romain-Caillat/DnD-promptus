# Lire les intentions ennemies

**État** : tranchée · 11/10/2026

**Règle** : Si ta Perspicacité est assez haute, tu sais avant son tour quelle cible et quelle action un ennemi a choisies.

**Schéma** :

```text
 gobelin ──▶ vise Léa, à l'arc
   Yann (Perspicacité ≥ seuil) : le sait avant le tour du gobelin
   Léa  (Perspicacité < seuil) : ne le sait pas
```

**Pourquoi** : SAG sert en combat ; repris d'Into the Breach.

**Impacts** : campagne — un seuil par adversaire · plateforme — l'intention n'est envoyée qu'à qui la lit
