# Jets

## Un vrai dé au milieu de l'écran
> **tranchée** 16/10/2026 · résolue par : —

```
 action choisie ──▶ ┌──────────┐ ──▶ issue : 1 · échec · réussite · 20
                    │  🎲 d20  │     (le DD était affiché avant)
                    └──────────┘
                    vu par tous les joueurs présents
```

- Chaque jet d'une action, en dialogue comme en combat, est **un dé en 3D qui roule au milieu de l'écran**.
- Tous les joueurs présents le voient.
- Le dé garde le look facetté du jeu.

**Pourquoi** : le jet est un moment partagé, comme autour d'une table.
