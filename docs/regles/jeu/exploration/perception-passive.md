# Perception passive

**État** : tranchée · 11/10/2026

**Règle** : Certaines choses ne se voient que si ta Perception passive est assez haute ; tu les découvres sans lancer de dé.

**Schéma** :

```text
 Perception passive = 10 + mod SAG (+ maîtrise)
   ≥ seuil de l'objet ──▶ tu le vois ; le narrateur te l'annonce, à toi seul
   < seuil            ──▶ il n'existe pas pour toi
```

**Détails** :

- deux joueurs ne voient pas forcément la même pièce
- même principe pour un indice de Perspicacité pendant un dialogue
- la découverte entre dans ton journal

**Pourquoi** : SAG sert hors combat, et chacun a son moment de découverte.

**Impacts** : campagne — l'Auteur pose un seuil sur ce qui est caché · plateforme — un élément caché n'est envoyé qu'à qui le voit
