# Explorer librement

**État** : tranchée · 11/10/2026

**Règle** : Hors combat, tu te déplaces librement dans le lieu, sans cases, et tu vois les autres joueurs qui s'y trouvent.

**Schéma** :

```text
 [!] quête   [?] mini-jeu   (certains indicateurs sont cachés)
 tu ──▶ t'approches ──▶ une action à portée : parler, fouiller, ouvrir
```

**Détails** :

- une seule vitesse, pas de course (12/10/2026)
- tu agis sur la chose la plus proche, une action à la fois
- un PNJ n'a de nom pour toi qu'une fois qu'il s'est présenté (12/10/2026)

**Pourquoi** : un hub se vit comme un lieu, pas comme un plateau.

**Impacts** : campagne — l'Auteur place PNJ, objets et indicateurs · plateforme — tes déplacements sont validés par le serveur
