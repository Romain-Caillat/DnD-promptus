# Les options payantes

**État** : tranchée · 16/10/2026

**Règle** : Une réplique peut coûter de l'or ; tu sais qu'elle existe et ce qu'elle coûte, même si tu ne peux pas encore payer.

**Schéma** :

```text
 4. « Une tournée pour tout le monde. »   5 po
    tu as 3 po ──▶ il te manque 2 po
```

**Pourquoi** : l'or gagné en jouant ouvre des portes que tu vois venir.
