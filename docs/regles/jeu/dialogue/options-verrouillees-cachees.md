# Options verrouillées cachées

**État** : tranchée · 16/10/2026

**Règle** : Une option que la classe ou les stats du joueur n'ouvrent pas est **cachée**, comme dans Baldur's Gate 3.

**Schéma** :

```text
 ce que Yann voit              ce que Léa voit
 1. « Une chambre. »           1. « Une chambre. »
 2. [Persuasion] … DD 12       2. [Perspicacité] « De qui as-tu peur ? »
```

**Détails** :

- Ce qu'une stat apporte se lit sur la fiche du perso, pas dans des options grisées.

**Pourquoi** : on ne voit que ce qu'on peut dire ; l'écran reste court.

**Impacts** : campagne — chaque option porte sa condition (classe, stat, objet) · plateforme — un joueur ne reçoit jamais une option qu'il ne peut pas ouvrir.
