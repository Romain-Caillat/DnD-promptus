# Choisir ta réplique

**État** : tranchée · 11/10/2026

**Règle** : Face à un PNJ, tu choisis une réplique dans une liste ; certaines demandent un jet, avec leur compétence et leur DD.

**Schéma** :

```text
 GORVIN, tavernier   « On ne pose pas de questions, ici. »
   1. « Je cherche une chambre. »
   2. [Persuasion] « Je saurai être discret. »   DD 12
```

**Détails** :

- pas de texte libre

**Pourquoi** : tout ce qui peut arriver est préparé ; le jeu dit ces branches à sa façon.

**Impacts** : campagne — l'Auteur écrit chaque réplique et son issue · plateforme — le narrateur ne choisit jamais une branche
