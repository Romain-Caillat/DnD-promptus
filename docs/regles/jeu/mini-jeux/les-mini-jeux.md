# Les mini-jeux

**État** : tranchée · 11/10/2026

**Règle** : Dans les hubs, des mini-jeux facultatifs de moins de 2 minutes te font gagner quelque chose ; ta compétence liée change la difficulté.

**Schéma** :

```text
 dés · crochetage · marchandage
 Escamotage ──▶ tu peux tricher aux dés
 gain : or · objet · rumeur · accès à une quête secondaire
```

**Détails** :

- possibles entre joueurs : les dés en duel

**Pourquoi** : chaque stat trouve son occasion hors combat, sans casser le rythme.

**Impacts** : campagne — l'Auteur habille chaque mini-jeu pour son lieu · plateforme — un catalogue de types programmés
