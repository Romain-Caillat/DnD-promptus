# Règles du jeu

Le livre du joueur : ce que tu peux faire, les dés que tu lances, ce qui en découle.
Une page par règle ; gabarit : [carte des docs](../../README.md). Comment c'est montré à l'écran : [plateforme](../../plateforme/README.md).
Les chiffres (DD, PV, portées) viennent du système de règles de chaque campagne ; les pages donnent la valeur par défaut.

**Références par défaut** : quand une règle est muette, on fait comme elles.

```text
 règles, stats, combat    DnD 5e (SRD), lu avec la clarté de Fire Emblem
 dialogue, vie de groupe  Baldur's Gate 3
 arcs personnels          Octopath Traveler
 intentions ennemies      Into the Breach
```
