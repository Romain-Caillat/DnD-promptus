# Un vrai dé au milieu de l'écran

**État** : tranchée · 16/10/2026

**Règle** : Chaque jet d'une action, en dialogue comme en combat, est **un dé en 3D qui roule au milieu de l'écran**.

**Schéma** :

```text
 action choisie ──▶ ┌──────────┐ ──▶ issue : 1 · échec · réussite · 20
                    │  🎲 d20  │     (le DD était affiché avant)
                    └──────────┘
                    vu par tous les joueurs présents
```

**Détails** :

- Tous les joueurs présents le voient.
- Le dé garde le look facetté du jeu.

**Pourquoi** : le jet est un moment partagé, comme autour d'une table.

**Impacts** : campagne — — · plateforme — le serveur tire le dé ; l'animation ne fait que montrer ce résultat (ticket `hd2d/roll-dice-in-3d`).
