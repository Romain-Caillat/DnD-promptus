# Une table de six

**État** : tranchée · avant la bible (leçons des parties)

**Règle** : La table compte jusqu'à six joueurs, chacun sur son PC.

**Schéma** :

```text
 6 joueurs  ⚔  6 adversaires
 lobby · écran · frise d'initiative · panneau MJ : tout tient à six
```

**Détails** :

- Tout écran, tout combat et tout ordre de tour doit tenir à six contre six.

**Pourquoi** : c'est la vraie table de Romain (partie des Corsaires).

**Impacts** : campagne — rencontres pensées pour six · plateforme — rien ne se dimensionne pour trois.
