# Voix entre joueurs

**État** : provisoire · 16/10/2026

**Règle** : Les joueurs se parlent par un outil externe (Discord…).

**Schéma** :


**Pourquoi** : un chat vocal intégré est une grosse brique sans gain de jeu.
