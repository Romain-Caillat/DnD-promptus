# Monde

## Ce que le monde retient de vos choix
> **à définir** · résolue par : —

```
 chapitre 1 : on ment à Gorvin ──▶ état « méfiant »
 chapitre 2 : Gorvin ──▶ répliques de l'état « méfiant »
```

**Question** : un PNJ, une faction se souviennent-ils de ce qu'on a fait, et le joueur le voit-il ?
**Options** : rien n'est retenu · états par PNJ (allié, méfiant, hostile) · états + affinité de faction.
**Recommandation** : états par PNJ, préparés par l'Auteur ; le jeu annonce discrètement « Gorvin s'en souviendra » ; factions plus tard.

**Pourquoi** : sans mémoire, les choix n'ont pas de poids ; chaque état est une branche à préparer.
**↳ campagne** : l'Auteur écrit les répliques de chaque état · **↳ plateforme** : l'état du monde survit d'un chapitre à l'autre.
