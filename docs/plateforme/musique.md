# Musique

## Lecteur YouTube synchronisé
> **tranchée** 11/10/2026 · résout : [Musique choisie, synchronisée](../regles/jeu/apparence.md)

```
 serveur : morceau + instant de départ ──▶ chaque joueur : lecteur YouTube visible
                                           démarre muet ──▶ « activer le son »
                                           pub ou décalage ──▶ se recale seul
```

- Le lecteur YouTube reste visible (conditions d'utilisation de YouTube).
- Il démarre muet : chaque joueur active le son une fois.
- Une publicité peut décaler un joueur ; la lecture se recale d'elle-même.

**Pourquoi** : choisir dans YouTube ne coûte rien à l'Auteur et sonne mieux qu'une génération.
**↳ jeu** : un joueur peut entendre un morceau avec quelques secondes de décalage · **↳ campagne** : plusieurs morceaux par scène.
