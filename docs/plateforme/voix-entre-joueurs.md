# Voix entre joueurs

**État** : provisoire · 16/10/2026

**Résout** : [Bible, « L'échelle »](../bible.md)

**Solution** : Les joueurs se parlent par un outil externe (Discord…) ; le jeu ne transporte aucun son entre eux.

**Schéma** :

```text
 joueurs ◀── Discord, à côté du jeu ──▶ joueurs     (aucun chat vocal dans le jeu)
```

**Pourquoi** : un chat vocal intégré est une grosse brique sans gain de jeu.
