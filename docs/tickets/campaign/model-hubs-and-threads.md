# campaign/model-hubs-and-threads · Modéliser hubs et fils

**État** : à faire · Jalon 1, phase « Parler »

**Réalise** : [Bible, « La boucle de jeu »](../../bible.md)

**Objectif** : Une scène est un hub, où chacun explore seul, ou un fil, où le groupe est réuni.

**Périmètre** :

- une scène est un **hub** ou un **fil**
- un hub déclare sa convergence : événement préparé, tout le monde prêt, ou un joueur qui déclenche
- champs facultatifs : un ancien fichier s'importe toujours

**Fini quand** : La taverne de Port-Louis est un hub, avec sa convergence vers le fil, et le validateur la vérifie.

**Départ** : `campaign/model-story-graph`, `campaign/edit-scenes-in-one-place`
