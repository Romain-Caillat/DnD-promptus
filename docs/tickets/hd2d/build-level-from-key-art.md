# hd2d/build-level-from-key-art · Construire un niveau depuis une illustration

**État** : à faire · Jalon 1, phase « Le monde »

**Réalise** : [Rendu des lieux peints](../../plateforme/rendu-des-lieux.md)

**Objectif** : L'Auteur transforme une illustration de lieu en niveau jouable, sans code propre à ce lieu.

**Périmètre** :

- outiller la recette : illustration, décor vide, plans découpés avec leur ligne de sol, persos dans le style
- données de sol (zones praticables, obstacles, points d'interaction), lumières
- le format d'un niveau en données, lu par le jeu
- un éditeur de polygones pour l'Auteur
- coût annoncé avant chaque lot de générations

**Fini quand** : Le Perroquet Noyé et le quai de Port-Louis sont des niveaux en données, jouables à 60 images/s, sans code propre à l'un d'eux.

**Départ** : `docs/design/v2/taverne-hd2d.html`
