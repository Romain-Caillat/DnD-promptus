# engine/fix-stats-by-class · Fixer les stats par la classe

**État** : à faire · Jalon 1, phase « Maquettes et règles »

**Réalise** : [Moteur de règles en données](../../plateforme/moteur-de-regles.md) · [Créer ton personnage](../../regles/jeu/personnage/creer-ton-personnage.md)

**Objectif** : Le joueur choisit sa classe, et ses stats en découlent.

**Périmètre** :

- chaque classe déclare la répartition du tableau standard (15, 14, 13, 12, 10, 8)
- la création n'offre plus de choix de stats
- l'Auteur peut limiter les classes d'une campagne

**Fini quand** : Un personnage de chaque classe des Corsaires est créé sans choisir ses stats.
