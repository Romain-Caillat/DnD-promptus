# engine/time-turns · Minuter les tours de combat

**État** : à faire · Jalon 1, phase « Combattre »

**Réalise** : [Moteur de règles en données](../../plateforme/moteur-de-regles.md) · [Ton tour](../../regles/jeu/combat/ton-tour.md)

**Objectif** : Un tour de combat dure 60 secondes ; personne n'attend un joueur absent.

**Périmètre** :

- 60 secondes par tour, données du système de règles
- temps écoulé : le serveur fait jouer l'action Esquiver
- le MJ peut mettre en pause

**Fini quand** : Un tour expiré passe en Esquiver chez tous les joueurs.
