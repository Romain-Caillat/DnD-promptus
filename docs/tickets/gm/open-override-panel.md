# gm/open-override-panel · Ouvrir le panneau d'override

**État** : à faire · Jalon 1, phase « Autour du jeu »

**Réalise** : [Bible, « Écran MJ »](../../bible.md)

**Objectif** : Le MJ débloque une situation sans que les joueurs le voient.

**Périmètre** :

- le panneau par-dessus l'écran de joueur du MJ (`Tab`) : joueurs et activité
- alertes : bloqué, conversation en boucle, temps qui dérape
- pause globale, forcer/annuler un jet ou une action, déplacer un perso, déclencher la convergence
- overrides invisibles pour les joueurs ; routes derrière la garde MJ

**Fini quand** : À la soirée, Romain débloque une situation sans que les joueurs le voient.

**Départ** : `gm/run-live-screen`, `gm/adjust-sheets-fast` (gelés)
