# session/create-character · Créer son personnage

**État** : à spécifier · Jalon 1, phase « Autour du jeu »

**Réalise** : [Classes, prétirés et arcs personnels](../../regles/campagne/reglages/classes-pretires-et-arcs-personnels.md)

**Objectif** : Chaque joueur crée son perso, avec son sprite et son portrait.

**Périmètre** :

- race → classe (une par joueur, stats fixées) → historique → apparence → nom
- apparence : une description ; PixelLab pour le sprite, l'IA pour le portrait et le portrait « en action »
- prétirés en option
- **à spécifier** : qui paie les générations, combien de propositions on montre

**Fini quand** : Chaque joueur de la soirée a créé son personnage, avec son sprite et son portrait.

**Départ** : `characters/build-character-creator`, `hd2d/show-pixellab-characters` (gelés)
