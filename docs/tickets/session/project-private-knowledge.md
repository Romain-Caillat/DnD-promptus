# session/project-private-knowledge · Projeter un savoir privé par joueur

**État** : à faire · Jalon 1, phase « Autour du jeu »

**Réalise** : [Ce que tu sais t'appartient](../../regles/jeu/exploration/ce-que-tu-sais-t-appartient.md)

**Objectif** : Ce qu'un joueur découvre, les autres ne le savent pas tant qu'il ne l'a pas partagé.

**Périmètre** :

- la projection joueur devient **par joueur** : indices, dialogues, objets et Perception filtrent ce que chacun reçoit
- les noms aussi : un PNJ reste une description (« Marin ») tant qu'il ne s'est pas présenté, narrateur compris
- le MJ voit tout
- tests de fuite entre deux joueurs

**Fini quand** : Aucun test de fuite ne montre un savoir d'un joueur chez un autre.

**Départ** : `session/project-player-view`, `session/track-table-knowledge`
