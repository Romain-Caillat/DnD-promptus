La salle de l’autel

Le co-MJ propose la salle à partir du graphe ; Romain la retouche outil par outil et vérifie ce que verront les joueurs.

1Jamais de page blanche. Chaque lieu arrive avec une carte proposée.
2Caché veut dire non envoyé. Le serveur garde les secrets, pas les téléphones.
3Les échelles se relient. Chaque sortie ouvre la bonne carte en jeu.
1La proposition
Romain
Décide de retoucher.
Le co-MJ
Dessine la salle depuis le graphe.
Pourquoi
Le MJ part d’une proposition.
2Murs et eau
Romain
Peint l’eau au sud.
Le co-MJ
Rappelle le terrain difficile.
Pourquoi
Un terrain porte sa règle.
3Portes et décors
Romain
Pose une porte secrète.
Le co-MJ
Propose de l’ajouter au graphe.
Pourquoi
Les décors viennent du pack.
4Objets cachés
Romain
Cache la page sous l’autel.
Le co-MJ
Rappelle l’indice 3 sur 3.
Pourquoi
Un secret a son jet.
5Lumières
Romain
Allume deux braseros.
Le co-MJ
Note que Borin voit dans le noir.
Pourquoi
La lumière décide de ce qu’on voit.
6Vue des joueurs
Romain
Vérifie le brouillard.
Le co-MJ
Confirme : rien d’envoyé.
Pourquoi
Le MJ voit comme ses joueurs.
7Les sorties
Romain
Valide la carte.
Le co-MJ
Propose la salle est.
Pourquoi
Les sorties ouvrent les lieux suivants.
