Les règles de Valombre

Romain part du SRD de D&D 5e et l’ajuste pour sa table : cases, difficultés, actions, une règle maison, puis un combat simulé.

1Une copie, jamais le préréglage. Les changements restent dans la campagne.
2En français. Le MJ écrit sa règle, le co-MJ la formalise, le MJ relit.
3Tester avant de jouer. Une simulation montre l’effet des choix.
1Le préréglage
Romain
Personnalise le SRD.
Le co-MJ
Liste ce qu’il contient.
Pourquoi
On part d’un système complet.
2Les statistiques
Romain
Compte le mouvement en cases.
Le co-MJ
Convertit : 6 cases.
Pourquoi
Les gemmes suivent les statistiques.
3Les jets
Romain
Passe « facile » à 12.
Le co-MJ
Chiffre l’effet : 65 %.
Pourquoi
Quatre difficultés, données d’un clic en jeu.
4Les actions
Romain
Désactive « Saisir ».
Le co-MJ
Adapte le chef gobelin.
Pourquoi
Les actions sont les cartes des joueurs.
5Une règle maison
Romain
Écrit : les morts-vivants ont peur du feu.
Le co-MJ
La formalise, avec trois cas.
Pourquoi
Le MJ valide ce qu’il lit.
6La création
Romain
Fixe 27 points, niveau 1.
Le co-MJ
Prépare les cartes de départ.
Pourquoi
Ces limites pilotent le créateur des joueurs.
7La simulation
Romain
Verrouille la version 2.
Le co-MJ
Simule 200 combats : 87 %.
Pourquoi
Le MJ voit l’effet avant la table.
