Hugo joue Sef sur son ordi

Le même jeu que sur téléphone, déplié sur un grand écran : la scène, la main, la carte et le combat côte à côte, au clavier.

1Les mêmes règles. Rien de plus sur ordinateur, tout est visible d’un coup.
2Le clavier aide. Raccourcis pour les cartes, espace pour le dé.
3Le MJ valide. Une action proposée attend toujours le MJ.
1La scène
Hugo

Hugo

Romain

Les cartes ont leur raccourci.
