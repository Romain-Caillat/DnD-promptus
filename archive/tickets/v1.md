# Archive — V1 (Next.js)

Ce qui a été livré dans la V1, avant la réécriture. Le code est dans
`archive/promptus-v1-nextjs.zip` ; il sert de référence fonctionnelle.
Les décisions durables qui en sont issues vivent dans `MEMORY.md`.

| Épic V1 | Ce que ça a apporté |
| --- | --- |
| MVP | Moteur déclaratif (20 effets primitifs, 14 conditions 5e, résolveur d'attaque L3), cockpit par phases (abandonné en V2), catalogue audio, import/export YAML des entités |
| E0 Assainissement | Tests unitaires et d'intégration séparés, lint, `.env.example`, suppression des mocks, interface en français |
| E1 Modèle de campagne + règles | Bible, fronts, nœuds, indices, cartes, état vivant ; système de règles défini par le MJ (préréglage D&D 5e SRD) |
| E2 Génération de campagne | Pitch → structure générée par LLM (OpenRouter), validée par schéma, relue et corrigée par le MJ avant application |
| E3 Pipeline média | Images et vidéos en tâches asynchrones, musique YouTube par scène, estimation du coût et budget, verrou d'écriture par campagne |
| E4 Cartes à grille | Trois niveaux (campagne, région, combat), données séparées du fond, brouillard de guerre |
| E5 Session temps réel | Lien d'invitation, lobby, serveur WebSocket relayant les notifications Postgres, présence |
| E6 Interface joueur | Scène, carte (zone révélée), fiche, groupe et initiative, actions permises par les règles, demandes au MJ, journal public |
| E7 Co-MJ en direct | Décrire, conséquences, et ensuite, faire parler un PNJ ; réponses modifiables, suggestions applicables, identifiants inventés écartés |
| E8 Combat sur grille | Pions, initiative, déplacement vérifié par le serveur, attaques avec portée et ligne de vue |
| E9 Continuité | Fin de session, récapitulatifs MJ et « Précédemment… », chronique de campagne |

**Jamais essayé en vrai** : une session complète à distance avec de
vrais joueurs, la vidéo OpenRouter, l'écran joueur sur téléphone.
